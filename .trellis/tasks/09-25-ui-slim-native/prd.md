# UI 冗余精简、按钮解耦复用与去特效原生化

> 父任务：`09-25-workbench-native-onesop`。诊断依据：`09-25-live-perf-diagnosis/research/live-report.md`。
> **本 PRD 的全部条目均来自用户 2026-09-25 的逐项裁决**（原话见各条「裁决依据」），未经裁决项一律不做。

## Goal

把插件工作台从「1237px 平铺表单」收敛为**原生风格的渐进披露界面**：
首屏只看得到「我现在能做什么」，高级项收进宿主原生折叠抽屉，且**界面上不出现任何解释性文案**。

## Background

### 诊断事实（`live-report.md` §1.1 / §3.1）

| 项 | 实测 |
| --- | --- |
| 插件 UI 高度 | **1237 px**（474px 侧栏 → 约 1.7 屏连续滚动） |
| DOM / 按钮 / 输入控件 | 276 / 36（可见 13）/ 19（8 复选框 + 4 单选 + 7 下拉文本） |
| 性能 | 启动期 0.05%、刺激期 0%、交互期 0.06% —— **性能不是问题，规模才是** |
| 可见按钮全清单 | `+ {part}` `+ {user}` `+ {date}` `+ {category}` `+ {mode}` `+ {target}` / 分卷标准 核心备份 全量备份 / 开始转换 从宿主拉取 恢复到当前用户 / 展开日志 |
| 暂存区 | 每行 4 按钮（载入/下载/写回宿主/删除）+ 批量条同样 4 按钮 = **双重表达**；用原生 `confirm()` 而非酒馆 `callGenericPopup` |
| 双入口 | `index.html`（441 行旧多抽屉结构）与 `workbench-template.js`（两块式）**结构已分歧**，独立态 `refreshArchiveManagerUI()` 早退（L1-MR-10 违规） |

## Requirements

### R1 信息架构重排（分区 + 折叠）

分区与披露级别（**仅 G 常驻**，其余按表）：

| 区 | 内容 | 披露 |
| --- | --- | --- |
| A 状态 | 合并徽标 | 常驻 |
| B 源包 | 拖放区 + 源包列表 | 常驻 |
| C 产物 | 待导出区 | 常驻 |
| D 执行 | 进度条 + 暂停/中止/继续/丢弃 + 报告统计（空状态隐藏） | 常驻 |
| E 动作 | 从宿主拉取 / 开始转换 / 恢复到当前用户 | 常驻 |
| F 输出目标 | 目标平台 + 压缩率 + 智能分包（数值） | 常驻 |
| G 内容范围 | 类目选择 + 摘要 | **常驻**（用户明确） |
| H 垃圾清理 | git 清理 / 剔除原生重复资产 / 派生缓存 / 私有配置 / 备份快照 | 折叠，**默认全启用** |
| I 扩展打包 | 两个紧凑格式选项 + 保留构建配置 | 折叠 |
| J 增量与差量 | 增量合并 + 差量补丁 + 基准 ZIP | 折叠 |
| K 包名 | 输入框 + 实时预览 | 折叠 |

- **R1.1** 折叠必须使用宿主原生 `.inline-drawer` 结构 + 既有 `setupDrawerToggles()`（`host-bridge.js:1168`），样式走已作用域化的 `style.css:2020-2058`，**不新造折叠组件**。
- **R1.2** 每个折叠区标题栏须显示足以判断当前状态的摘要（如 H 显示「垃圾清理 · 已启用 5 项」），让用户不必展开即可知情。

### R2 移除项（用户裁决 4/6）

- **R2.1** 移除 6 个包名占位符 chip；保留输入框，可用占位符通过 placeholder 表达。
- **R2.2** 移除 3 个包名预设按钮。
- **R2.3** 移除「角色与聊天智能联动」复选框，行为改为**恒开**（联动逻辑保留）。
- **R2.4** 移除扩展模式的大段描述文字，改为两个紧凑选项。

### R3 智能分包改数值输入（用户裁决 5）

- **R3.1** `#split-select` 改为数值输入：**仅接受整数**，带**最小值限制**（最小 1 MB），空值/0 = 不分卷。
- **R3.2** 非整数输入必须被拒绝或归一，不得把浮点传进分卷逻辑。

### R4 零解释性静态文案（用户裁决 12）

- **R4.1** 清除全部描述段（`<p class="sub-text">`、`<small class="zone-hint">` 等）、括号补充说明、教学性 `title=` 文案。
- **R4.2** **保留**：错误提示、状态/进度文案、输入框 placeholder、图标自身的悬停名称、类目摘要等**状态读数**。
- **R4.3** 页脚/页头里的说明性语句一并清理（保留仓库链接本身）。

### R5 暂存区优化（用户裁决 9/15）

- **R5.1** 每行动作缩为**「载入」+「⋯」（更多）**，更多菜单内含 下载 / 写回宿主 / 删除。
- **R5.2** 批量条保留多选后的统一操作。
- **R5.3** 删除确认由原生 `confirm()` 改为宿主 `callGenericPopup`（Luker/ST 可用时），不可用时降级回 `confirm()`。

### R6 报告统计空状态隐藏（用户裁决 11）

- **R6.1** 无源包/无产物时 `#report-panel` 不渲染（不占位、不留空白）。

### R7 按钮职责与解耦（用户裁决 8 + 「怎么解耦复用按钮」）

- **R7.1** 三枚动作按钮**全留**，且必须支持**同时可见**（对应「上传暂存 → 清理 → 转换/导出」与「宿主拉取 → 转换 → 恢复」两条并行流程）。
- **R7.2** 三枚按钮的启用/可见条件当前散落在 `index.js` 多处（`btn-convert` 的 `disabled`、`btn-host-fetch` 的 `display`、`btn-restore-luker` 的 `disabled` + `lastConvertedBlob`），须**收敛为单一状态求值函数**（如 `computeActionAvailability(state)`），由它一处决定三枚按钮的可见与可用，UI 层不再散落判断。
- **R7.3** 按钮工厂复用：工作台按钮与宿主注入按钮（`mountNativeBackupButton` / `mountLukerBackupManagerButton`）当前各自 `makeButton`，须收敛为同一工厂（统一图标/文案/禁用态处理）。

### R8 双入口单一模板源（用户裁决 14）

- **R8.1** `index.html` 收敛为骨架（仅 `<div id="app" class="app-container">` + 脚本入口），**内容由 `getWorkbenchHtml()` 生成**，与插件态/模态态共用同一模板函数。
- **R8.2** `getWorkbenchHtml()` 增加独立态分支参数，三态（独立/插件抽屉/模态）由同一函数产出。
- **R8.3** 加**机器化自查**：断言 `index.html` 不再含任何业务节点 id（防止回归成两份副本）。CLI 约定沿用 `scripts/css-scope.js`（违规退出码 1、输出 `文件:行号`）。
- **R8.4** 不要求用户跑构建；不引入外部 CDN。

### R9 贯穿约束

- **R9.1** CSS 双前缀铁律不得回归：`npm run check:css-scope` 必须通过。
- **R9.2** DOM 注入不得引入未转义插值：`npm run check:dom-injection` 必须通过。
- **R9.3** `npm test` 全绿、零回归（当前基线 226 passed / 2 skipped / 34 文件）。
- **R9.4** 配色一律 `var(--SmartTheme*, 回退值)`，禁止硬编码（含移除 09-07 遗留的金色系硬编码）。
- **R9.5** 复用宿主原生类（`menu_button` / `inline-drawer` / `text_pole` / `checkbox_label`）只出现在标记里，样式仍全部作用域化。
