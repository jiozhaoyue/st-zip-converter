# 批量数据包队列、链式多跳转换流水线与多端体验精修

## Goal

针对用户对控制台布局、交互细节与功能扩展提出的明确反馈，进行系统级优化：
1. **双列表常驻展示**：取消折叠与隐藏逻辑，双文件列表（已上传源包 / 已转换生成包）在界面中始终常驻展示，一眼尽览；
2. **自定义包名可点击占位符标签与说明**：提供 `{source}`, `{target}`, `{date}`, `{handle}` 等交互式药丸芯片，点击即插，并提供清晰的变量含义说明；
3. **多端精简与排版消除不自然折行**：彻底移除冗余副标题说明，针对移动端与桌面端优化布局，消除任何单字不自然换行与拥挤；
4. **批量数据包队列与多跳链式流转**：支持同时拖入或多选多个 Zip 数据包批量入库，提供批量队列转换与产物一键作为新源包的多跳流转能力。

## Requirements

### 1. 双列表常驻化与极简展示
- 移除 `#btn-toggle-workspace` 折叠控制与任何隐藏样式；
- `#workspace-panel` 始终可见，常驻于主界面的数据处理区；
- 左右分栏分别展示【📥 已上传源包】与【📤 已转换生成包】；
- 移除列表头部的冗余副标题说明，保持界面极简、高级与专注。

### 2. 自定义文件名占位符交互芯片
- 在自定义文件名输入框下方提供药丸标签组：
  - `+ {source}` (源文件名)
  - `+ {target}` (目标平台: st/l/tt/pt)
  - `+ {date}` (当前时间戳)
  - `+ {handle}` (用户标识)
- 点击标签即刻插入占位符到输入框中，并触发变更存储；
- 提供紧凑说明文本，提示占位符用途与非法字符自动过滤保障。

### 3. 多端响应式精修与排版优化
- 移除快捷导出按钮内的副标题说明（`.desc`），使按钮更紧凑、专注、无不自然换行；
- 优化按钮组与控制栏在窄屏（移动端/平板）下的流式布局，关键信息（徽标、药丸、操作按钮）一律采用 `white-space: nowrap` 防止折行；
- 消除任何边缘溢出或生硬截断。

### 4. 批量数据包队列与一键多跳流转
- 拖拽区与文件选择控件支持一次性拖入或选取多个 Zip 数据包；
- 批量自动解析并存入 IndexedDB 源包库；
- 工作区提供一键批量转换所有未转换源包的能力，按序执行并汇报总进度；
- 生成包可秒级载入为源包，无缝支持 ST → TT → PT 的链式多跳互转。

## Acceptance Criteria

- [x] 双列表完全取消折叠，始终常驻可见，移除折叠开关。
- [x] 自定义包名输入框配备可点击的占位符药丸芯片，点击即可插入变量。
- [x] 界面彻底移除不必要的副标题说明，彻底消除多端下的不自然换行。
- [x] 支持多文件同时拖入/选择入库，并能在源包列表中清晰列出。
- [x] 产物列表支持一键作为源包继续流转到不同目标。
- [x] 单元测试通过率 100%，生产构建顺畅无阻。
