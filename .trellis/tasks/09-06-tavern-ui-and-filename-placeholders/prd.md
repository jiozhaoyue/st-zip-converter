# 酒馆风格 UI 重构与导出名占位符修复 (Tavern UI & Filename Placeholders)

## Goal

1. 将整个应用（包括独立 Web 模式与 SillyTavern/Luker 嵌入模式）全面重构为 SillyTavern 酒馆视觉风格，支持原生酒馆 CSS 变量继承（--SmartTheme*）与自适应琥珀金/深邃夜色质感。
2. 彻底排查并修复宿主酒馆直接导出以及外部 Zip 转换流程中导出名自定义模板与占位符（{source}, {target}, {handle}, {date} 等）失效的缺陷，提供占位符别名兼容与实时效果预览。

## Requirements

### R1: 导出文件名模板与占位符缺陷彻底修复
- **R1.1 宿主原生导出文件名解析**: 在 `handleHostExport` 中，无论直出为 native 还是跨格式，均严格执行模板解析，杜绝原生导出时直接绕过 `resolveFilename` 造成占位符完全失效。
- **R1.2 用户 Handle 贯通**: 宿主导出和单包/批量转换时，将真实用户句柄（通过 `/api/users/me` 嗅探、manifest 读取或包内目录推导）传入 `resolveFilename`，解决 `{handle}` 永远为 `default-user` 的问题。
- **R1.3 占位符丰富度与别名扩展**: `resolveFilename` 扩展兼容 `{name}`, `{filename}`, `{user}`, `{username}`, `{time}`, `{datetime}`, `{timestamp}`, `{platform}`, `{layout}`。
- **R1.4 智能点击插入体验**: 修复占位符药丸芯片点击逻辑，解决未对焦时盲目插入到最前端的 Bug，确保始终智能拼接至 `.zip` 之前。
- **R1.5 实时生成效果预览**: 在包名输入框下方提供动态预览标签，即时展示当前模板结合源文件、目标格式、用户句柄与时间戳解析后的实际文件名。
- **R1.6 宿主导出区专属配置**: 宿主直接导出工作台与外部互转区均能直观看到或联动设置导出包名。

### R2: 界面全面重构为 SillyTavern 酒馆视觉风格
- **R2.1 色彩与主题变量体系**: 采用 SillyTavern 经典暗色酒馆主题，以沉稳黑曜/深灰为基底，以温暖琥珀金（#f59e0b / #d97706 / #b45309）和神秘紫为主辅强调色，优先继承宿主 `--SmartThemeBodyColor`、`--SmartThemeBorderColor`、`--SmartThemeChatTintColor` 等变量。
- **R2.2 质感与玻璃拟态 (Glassmorphism)**: 卡片容器采用精细磨砂玻璃质感（`backdrop-filter: blur(16px)`）、微光金边与柔和环境阴影，符合酒馆羊皮纸与冒险者公会公告栏韵味。
- **R2.3 按钮与控制组件重构**:
  - 主按钮（导出/转换/确认）采用酒馆琥珀金微渐变与光晕。
  - 药丸芯片（占位符、预设、类目标签）采用精致酒馆勋章样式。
  - 拖拽区域升级为复古酒馆行囊/羊皮卷轴质感，虚线边框与悬浮动态光效。
- **R2.4 双文件列表与日志控制台美化**:
  - 暂存源包与产物列表采用酒馆物品栏/藏宝箱网格排版，状态微标更醒目。
  - 实时日志抽屉升级为羊皮纸冒险日志/便携终端风格，支持平滑滚屏与级别滤镜。
- **R2.5 现代 Web 标准合规**: 遵照 modern-web-guidance 规范，表单控件使用 `accent-color` 与完善的回退策略，确保键盘无障碍与移动端触控区 >= 44px。

## Acceptance Criteria

- [ ] 无论在宿主模式（原生导出、跨格式直出）还是外部包转换（单包、批量），自定义文件名模板与占位符均 100% 正确解析并生效。
- [ ] `{handle}` 占位符在宿主环境中能正确替换为当前登录用户名，在外部包转换中若能提取用户目录或 manifest 则准确填入。
- [ ] 输入框输入或点击占位符芯片时，实时预览标签无延迟更新渲染最终文件名。
- [ ] 占位符药丸芯片点击时不会错位插入到最前端，能智能位于扩展名前。
- [ ] UI 呈现纯正 SillyTavern 酒馆风格，卡片、按钮、输入框、进度条、抽屉日志及弹窗风格统一协调，支持宿主主题变量无缝融合。
- [ ] `npm test` 全量单测通过（包含新增模板解析与 UI 逻辑测试），`npm run build` 构建无警告无错误。
