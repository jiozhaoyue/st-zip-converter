# 构建浏览器 IndexedDB 工作区持久化与单项穿透动作预览

## Goal

为 `st-zip-converter` 打造专业级数据包工作站基石：
1. 实现基于浏览器 IndexedDB 的数据包暂存与工作区状态自动恢复（刷新或下次打开不丢失）；
2. 构建完全扫描（Deep Scan）与转换动作预览预测引擎，在真正转换前向用户透明呈现每一项资产的处理方式（直通、路由、迁移、合成、丢弃）；
3. 升级类目选择器为可穿透树形勾选器（支持单个角色卡、单条聊天记录、单个扩展独立剔除与搜索过滤）；
4. 分离派生缓存、历史备份与应用私有数据，提供精细控制；记忆用户勾选偏好。

## Requirements

### 1. IndexedDB 存储与工作区恢复
- 建立 `st_zip_converter_db`（包含 `files`, `workspace`, `preferences` 存储空间）。
- 上传的源 Zip 自动异步存入 IndexedDB，记录文件名、大小、布局与哈希。
- 页面加载时自动恢复上次会话（还原当前文件、目标平台选择与勾选状态）。
- 转换产物同时支持在工作区暂存与多次随时下载。
- UI 顶部或底部展示工作区缓存用量（如 `已暂存 1 个包 · 18.5 MB`）与一键清空/释放缓存按钮。

### 2. 完全扫描（Deep Scan）与动作预测引擎
- 在 `src/core/plan-preview.js` 中实现转换规划引擎：
  - 遍历中央目录分析每个文件在目标平台（ST/Luker/TT/PT）下的归宿。
  - 预测动作标签：
    - `COPY`（直通流拷贝）
    - `ROUTE`（路径映射，如 ST 摊平与 TT `data/default-user/` 相互转换）
    - `MIGRATE`（扩展迁移，如用户级 `extensions/` 转换为 PT 的 `data/extensions/third-party/`）
    - `SYNTHESIZE`（合成清单与来源记录，如 `manifest.json`）
    - `DROP`（丢弃派生缓存或平台不兼容私有数据）
    - `FILTER`（用户手动反选排除）
  - 输出结构化的预测报告与预估产物体积。

### 3. 可穿透勾选（Item-Level Granular Picker）与搜索过滤
- 类目面板支持展开各分类的文件详情清单。
- 支持单文件/单条目级别的复选框（例如单独排除某张角色卡 `alice.png` 或某个聊天记录）。
- 父级类目复选框自动联动 `indeterminate`（部分选中）状态。
- 内置即时搜索框，支持在成百上千个文件中按名称过滤定位。

### 4. 缓存、备份与私有数据彻底解耦
- 将派生缓存（`thumbnails/`, `_cache/`）、历史备份（`backups/`）与私有配置（`tauritavern-settings.json`, `_engine_*`）作为独立可选项。
- 替代粗粒度的 `--keep-all`，用户可单独决定是否带上历史备份或是否保留私有配置。

### 5. 偏好持久化
- 用户的常用勾选组合、目标平台偏好自动记忆到存储中，下次直接生效。

## Acceptance Criteria

- [x] IndexedDB 正常读写源包与产物，刷新浏览器后页面自动无损恢复工作区状态。
- [x] 完全扫描能够秒级输出全量条目的动作预测（直通、路由、迁移、合成、丢弃）。
- [x] UI 支持展开查看分类下的每个文件，并支持单个文件粒度的独立反选。
- [x] 转换引擎 `convert()` 支持 `excludedPaths: Set<string>` 穿透剔除未选文件。
- [x] 派生缓存、历史备份、私有数据分别提供独立显式开关。
- [x] 单元测试覆盖 IndexedDB 存储逻辑、规划预测引擎与路径级过滤排除。
- [x] `npm test` 100% 通过，`npm run build` 打包正常。
