# 全能工作站控制台：双文件列表、自定义包名/压缩率与高级动作联动

## Goal

响应用户的核心反馈，将 `st-zip-converter` 升级为具备完整工作站管控能力的备份处理中心：
1. **双文件列表管理**：工作区清晰分离展示【已上传/暂存源包列表】与【已转换生成包列表】，支持随时切换、回检、重新下载与删除；
2. **动作胶囊联动筛选**：点击完全扫描动作条中的 `直通`、`路由`、`迁移`、`丢弃`、`排除` 胶囊，实时过滤下方的文件树列表；
3. **体积排序与大文件醒目标记**：文件树支持按体积降序排序，>1MB 显示醒目黄标，>5MB 显示强提醒橙红标；
4. **自定义导出包名**：提供灵活的自定义包名输入框与占位符变量（`{target}`, `{source}`, `{date}`, `{handle}`）；
5. **Zip 压缩率调节与酒馆兼容性**：支持 0（未压缩/极速存储）、1（快速）、5（默认均衡）、9（极限压缩），完全兼容 ST、Luker、TT、PT 的解压标准。

## Requirements

### 1. 工作区双文件列表 (Source vs Output Archives)
- 在工作区状态栏中提供可折叠展开的双栏管理面板：
  - **已上传源包 (Sources)**：展示文件名、体积、识别布局、上传时间，提供【切换载入】与【删除】按钮。
  - **已转换生成包 (Outputs)**：展示文件名、体积、目标平台、生成时间，提供【重新下载】、【载入为源包继续转换】与【删除】按钮。
- 数据持久化保存在 IndexedDB 的 `files` 集合中（按 `role: 'source' | 'output'` 区分）。

### 2. 动作胶囊联动筛选 (Action Pill Filtering)
- 点击动作汇总条的胶囊（如 `路由 8`），高亮激活该胶囊，下方的文件树列表即刻仅展示动作为 `ROUTE` 的条目；
- 再次点击或点击【全部】重置筛选条件。

### 3. 文件体积排序与大文件预警标记
- 在各分类展开搜索栏旁增加排序切换：【默认排序】/【体积降序】/【名称 A-Z】；
- 对大于 1MB 的条目打上 `[⚠️ >1MB]` 标识，大于 5MB 打上 `[🔥 >5MB]` 警示标，便于用户快速定位占用过大体积的素材或聊天历史。

### 4. 自定义导出包名
- 在控制栏中添加导出文件名输入框：
  - 默认模板：`{source}-to-{target}-{date}.zip`；
  - 支持即时编辑与保存偏好；
  - 自动校验扩展名 `.zip`。

### 5. Zip 压缩率调节与格式兼容
- 控制栏提供压缩率选择：
  - `0 (极速存储 Store)`：零压缩开销，极速生成（适合已有大量 PNG/WebP/MP3 音视频的备份包）；
  - `1 (快速压缩)`：轻度压缩，速度极佳；
  - `5 (标准压缩，默认)`：平衡体积与速度；
  - `9 (极限压缩)`：最大化缩小 zip 包体积。
- 保证生成的压缩包完全兼容 ST、Luker、TT 的 Rust `zip-rs` 解压器与 PT 的 WebAssembly 解压器。

## Acceptance Criteria

- [x] 工作区提供已上传源包与已生成产物的双列表管理，支持切换、下载与删除。
- [x] 点击动作条胶囊可联动过滤文件树显示。
- [x] 文件树支持体积降序排列，大文件（>1MB / >5MB）有明确视觉标示。
- [x] 导出包名支持用户自定义输入与占位符变量解析。
- [x] Zip 压缩率可在 0、1、5、9 之间调节，并在实际 ZipWriter 中生效。
- [x] 单元测试覆盖双列表存储分类、动作过滤逻辑与不同压缩率转换。
- [x] `npm test` 100% 通过，`npm run build` 打包顺畅。
