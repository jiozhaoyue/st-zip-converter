# 子代理协作规范（Subagent Collaboration）

> **适用范围**：本项目（及沿用本规范的其他仓）内，主代理需要拆分并行工作时。
> **规则层级**：MUST。违反即视为流程违规。

---

## G-1 来源唯一性：只准用"本 agent 自身的子代理功能" (MUST)

**规则**：派发子代理时，**只能使用当前 agent 平台自带的子代理能力**。

| 平台 | 允许 | 禁止 |
| --- | --- | --- |
| VS Code Copilot | `runSubagent` 工具 | 任何外部 agent 通道 |
| 通用表述 | "本 agent 自身的子代理功能" | "其他 agent" |

**明确禁止的"其他 agent"**（不限于此列表）：

- `trellis channel spawn` 派生的 claude / codex worker（外部 CLI 进程）
- `trellis channel run` 一次性外部 worker
- `pebrel agent delegate` / `pebrel pane send` 交给分屏里的其他 agent
- 手工拉起的外部 CLI agent：`claude`、`codex`、`gemini` 等
- 其他 IDE / 终端 / 浏览器里的 agent 会话

**原因**：跨 agent 通道不受本主代理控制——模型路由不透明、权限与写盘边界不可控、退出与清理无保证。
2026-09-23 实测：`trellis channel spawn` 派出的 worker 使用外部 CLI 进程，主代理无法保证其只读约束，用户随即要求全部终止。

**违反后果**：不可控进程在仓库内写文件、模型路由与成本失控、任务状态出现第二真相源。

---

## G-2 并行不阻塞：一次性并发派发，主代理同轮推进自身工作 (MUST)

**规则**：需要多个子代理时——

1. **在工具调用层一次性并发派发**：同一轮内并行发起多个子代理调用，不得一个接一个串行发起。
2. **主代理同轮并行推进自身工作**：同一轮里同时发起自己的检索 / 读取 / grep / 落盘等调用，与子代理并行执行。
3. **不得空等、不得轮询、不得排队**：禁止"派一个→等它回来→再派下一个"，也禁止 `wait` / 轮询式等待子代理。

**原因**：串行派发把并行工作退化为串行，主代理算力被浪费；用户明确要求（2026-09-23）"主代理不能被子代理阻塞，必须和多子代理同时并行运行"。

**违反后果**：任务耗时线性膨胀；主代理在等待期无所作为；长任务易被对话压缩打断。

---

## G-3 任务自包含 (MUST)

**规则**：每个子代理的提示必须自带以下四项，**不得假设它继承了主对话**：

1. **范围** — 具体文件路径 / 目录 / 模块，不写"看看相关代码"。
2. **问题** — 要回答的具体问题清单（可核查、可证伪）。
3. **期望输出** — 报告结构、必填字段（如 `file:line` 锚点、严重度、证据）。
4. **落盘路径** — 唯一允许写入的文件路径。

**违反后果**：子代理自由发挥 → 产出无法与主代理结论对齐，返工。

---

## G-4 写权限边界：禁止主代理与子代理写同一文件 (MUST)

**规则**：

- 子代理**默认只读**；需要落盘时，只写各自独占的产出文件。
- **同一文件同一时间只能有一个写者**。主代理写汇总/索引文件，子代理写各自分片文件。
- 子代理**禁止修改产品代码**（除非该子代理任务本身就是实现任务，且主代理明确划定了它独占的文件集）。

**违反后果**：并发写互相覆盖，且 diff 无法审出谁覆盖了谁。

---

## G-5 冲突与不可用时的回退 (SHOULD)

**规则**：若子代理能力不可用（平台不支持、额度耗尽、调用失败）：

- 不降级到"其他 agent"通道（违反 G-1）。
- 由主代理**自行串行完成**，并在任务 `implement.md` 记录降级原因。

**原因**：来源唯一性是硬约束，优先级高于并行度目标。

---

## 检查清单（派发前自检）

- [ ] 用的是本 agent 自带的子代理工具？（不是 `trellis channel spawn` / pebrel / 外部 CLI）
- [ ] 多个子代理在同一轮内**并发**发起？（不是 for 循环里逐个 await）
- [ ] 主代理同轮也发起了自己的工作调用？
- [ ] 每个子代理任务都写全了 范围 / 问题 / 输出 / 落盘路径？
- [ ] 没有两个写者指向同一文件？
- [ ] 子代理不会被要求改产品代码？（除非专项实现任务）
